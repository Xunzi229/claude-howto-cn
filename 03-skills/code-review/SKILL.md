# 代码审查技巧

该skills提供全面的代码审查能力，重点关注：

1. **安全分析**
   - 身份验证/授权问题
   - 数据暴露风险
   - 注入漏洞
   - 密码学弱点
   - 敏感数据记录

2. **绩效评估**
- 算法效率（Big O 分析）
   - 内存优化
   - 数据库查询优化
   - 缓存机会
   - 并发问题

3. **代码质量**
   - 坚实的原则
   - 设计模式
   - 命名约定
   - 文档
   - 测试覆盖率

4. **可维护性**
   - 代码可读性
   - 函数大小（应< 50 行）
   - 圈复杂度
   - 依赖管理
   - 类型安全

## 审核模板

对于审查的每段代码，请提供：

### 总结
- 整体质量评估（1-5）
- 主要发现很重要
- 推荐的优先领域

### 关键问题（如果有）
- **问题**：清晰的描述
- **位置**：文件和行号
- **影响**：为什么这很重要
- **严重性**：严重/高/中
- **修复**：代码示例

### 按类别划分的调查结果

#### 安全（如果发现问题）
列出安全漏洞并举例

#### 性能（如果发现问题）
通过复杂性分析列出性能问题

#### 质量（如果发现问题）
列出代码质量问题以及重构建议

#### 可维护性（如果发现问题）
列出可维护性问题并进行改进
